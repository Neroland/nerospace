# 货运平台

> 本页为机器翻译草稿，仅供参考，以英文版本为准：[English](../../Cargo-Pad.md)。

**货运平台**是自动化补给线的端点：一块发射台平板，带有 27 格货舱、可由管道供给的燃料缓存和航线选择器。在货物出发的地方建一个，在货物应到达的地方建一个，在第一个平台上放一枚[货运火箭](Cargo-Rocket.md)，货物就会在两者之间飞行，两端都无需有人值守。

## 配方

顶部是 Nerosteel锭围绕一个[货运船体](Cargo-Rocket.md)，中间是一个 Nerosium块，两侧各一个[火箭发射台](Rocket-Launch-Pad.md)，底部是一排 Nerosteel。它位于 Greenxertz 材料阶梯上，在 2 级火箭之后。

## 建造平台

货运平台**本身就是**一个发射台方块。围绕它建造通常的完整 **3×3** 发射台（货运平台可以是方阵中的任意一格）——货运火箭需要 2 级结构，与 2 级载人火箭的门槛相同。空手潜行右键点击平台可查看它构成的等级。

- 相邻的 **[燃料储罐](Fuel-Tank.md)** 会像为载人火箭加注一样为停靠的货运火箭泵送燃料。你也可以直接通过管道将火箭燃料输入货运平台：其燃料缓存（默认 16,000 mB）只接受火箭燃料，并以 80 mB/刻的速率泵入火箭。
- **[通用管道](Universal-Pipe.md)**可连接每一个面。货舱使用 Neroland Core 的面配置（STORAGE 预设——每个面都可输入／输出），因此管道会在出发地将货物推入，在目的地将送达的货物抽出；基础和高级[管道过滤器](Pipe-Filters-and-Upgrades.md)照常工作。使用[配置器](Configurator.md)可将某个面设为仅输入或仅输出。
- 货舱有 27 个槽位；服务器的 `cargoPadSlots` 设置（默认 18）决定其中有多少可用。锁定的槽位在界面中以较暗的颜色显示。

## 所有权

放置货运平台会使你成为其所有者。只有所有者（或在平台无主时的任何人）可以更改其目的地、计划和标志；任何人仍然可以通过界面或管道放入物品。只有当你在界面中将你的平台标记为**公开**时，其他玩家才能将货物运**往**你的平台。命名牌可为平台重命名；该名称就是其他玩家在其目的地列表中看到的名称。

已建立的[轨道空间站](Station-Charter.md)也算作目的地：飞往空间站的航班会降落在放置于空间站着陆台六格范围内的货运平台上。

## 界面

空手右键点击平台（或其火箭）。

| 控件 | 含义 |
| --- | --- |
| `<` `>` `x` | 在你可以发货的平台（你自己的、与你共享的、公开的平台、你的空间站）之间切换，或清除目的地。 |
| 计划 | **手动**（仅发射按钮）、**装满时发射**（每个可用槽位都有东西），或**每 N 分钟**（`-`/`+` 更改 N）。 |
| 缓存／火箭仪表 | 平台缓存中和停靠火箭中的燃料。 |
| 行程信息 | 针对当前货舱内容的报价：火箭必须携带的燃料和飞行时间。 |
| 空载返回 | 卸货后，火箭空载飞回本平台，而不是留在目的地。返程燃料在发射时扣除。 |
| 公开／私有 | 其他玩家是否可以将货物运往此处。 |
| 发射 | 当有加注了燃料的货运火箭停靠、已设定目的地且货舱不为空时亮起。 |
| 状态栏 | 上一次发射尝试的结果，然后是上一次航班的状态（运输中并显示倒计时、等待中、已送达、已装箱）。 |

## 飞行、抵达与等待

飞行时间和燃料来自行星注册表（公式参见[公共 API](Public-API.md)）：一次航班至少需要一分钟，跨维度以及在高重力世界之间耗时更长；燃料随载荷和出发地的重力增加。运输途中不会渲染任何东西——航班是一个服务器端计时器，**在服务器重启后依然有效**。

抵达时，火箭会出现在目的地平台上，并每两刻卸下一组物品，以便管道跟上。如果目的地未加载，航班会等待——Nerospace 从不为了送货而加载区块。如果目的地平台已不存在、上面已停有另一枚火箭，或其货舱已满，航班会**等待**并每 30 秒重试一次（`cargoHoldRetrySeconds`）；等待 30 分钟后（`cargoHoldTimeoutMinutes`），剩余货物会作为**货运箱**物品掉落在目的地位置。货物永远不会被删除。右键点击货运箱即可将其拆开。

比较器输出取决于货舱的装载量。

在创造模式世界中，`/nerospace gallery` 会在火箭行的北侧建造一条现成的货运线路（两个已设定航线的平台、一枚加注了燃料的火箭、一个已装货的货舱）——打开平台 A 并按下发射即可观看一次送货。

## 隐私

平台只在世界存档中储存其所有者的 UUID，以及（可选的）所有者与之共享的玩家的 UUID。`/neroland data eraseme` 会移除你的航线，解除你与平台的关联（平台作为共享世界内容保留），将你从所有访问列表中移除，并使你与你的航班脱离关联——货物本身仍会送达或装箱。这里的任何内容都不会被记录或发送到任何地方。参见 `PRIVACY.md`。
