# 创造源方块

> **已迁移到 Neroland Core。**创造存储方块现在作为 **`nerolandcore:creative_battery`**、**`nerolandcore:creative_fluid_tank`** 和 **`nerolandcore:creative_gas_tank`** 由共享的 [Neroland Core](Neroland-Core.md) 库提供（与普通的[电池](Battery.md)、[流体储罐](Fluid-Tank.md)、[气体储罐](Gas-Tank.md)和[物品存储器](Item-Store.md)一起）。完整详情请参阅 **Neroland Core 维基**（_Creative Source Blocks_ 页面）。 See the **Neroland Core wiki** (the _Creative Source Blocks_ page)
> for the full details.

Endless sources (and voids) for testing pipe networks — creative tab only, unbreakable in
survival, no recipes. Because Neroland Core ships no specific fluids or gases, two of them now
configure their resource in-world:

- **创造流体储罐**初始为**空**——手持装满的桶（例如火箭燃料桶）右键点击以设定无限流体。
- **创造气体储罐** **以第一次通过管道输入的气体作为其气体**（通过管道输入一些氧气即可设定）——它不再固定为氧气。
- **创造电池**和以前一样，是无限的能量源／汇。

Nerospace 的[通用管道](Universal-Pipe.md)仍然可以连接所有这些方块，因此同时安装两个模组时，`/nerospace gallery` 演示行的表现与以前相同。

另请参阅：[Neroland Core](Neroland-Core.md)、[通用管道](Universal-Pipe.md)、[电池](Battery.md)、[流体储罐](Fluid-Tank.md)、[气体储罐](Gas-Tank.md)、[物品存储器](Item-Store.md)。
