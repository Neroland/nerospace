# 外星装饰

一个 Greenxertz 装饰方块系列，用于外星建筑——你也可以随意用它们来建造。

## 概述

Six full-cube blocks in the green/steel Greenxertz palette. 六种 Greenxertz 绿色／钢色调色板的完整方块。它们构成了\*\*[外星建筑](Alien-Structures.md)\*\*，全部可在 Nerospace 创造模式物品栏中找到，可用镐挖掘，并掉落自身。

## 方块

| 方块    | ID                               | 说明                       |
| ----- | -------------------------------- | ------------------------ |
| 外星砖   | `nerospace:alien_bricks`         | 主要的墙体方块——错缝砌筑，钢质灰浆。      |
| 裂纹外星砖 | `nerospace:cracked_alien_bricks` | 用于遗迹的风化变体。               |
| 外星柱   | `nerospace:alien_tile`           | 带钢格的地板／广场铺砖。             |
| 外星瓦   | `nerospace:alien_pillar`         | 用于转角和墙柱的凹槽柱方块。           |
| 外星灯   | `nerospace:alien_lamp`           | 全亮度光源（亮度 15）——一块发光的绿色面板。 |
| 外星水晶块 | `nerospace:alien_crystal_block`  | 发光点缀（亮度 12）——簇状水晶。       |

## 详细信息

- 工具：镐 · 掉落：自身。
- 外星灯和外星水晶块会发光；其余为装饰方块。
