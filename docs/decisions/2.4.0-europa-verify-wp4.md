## Checked and OK

- **Version safety.** The only `//?` block in the new creature, model and renderer code is the `WaterAnimal` import in `E/entity/EuropaSwimmer.java:6-10`. The class is `net.minecraft.world.entity.animal.WaterAnimal` in 1.21.1, 1.21.4 and 1.21.10, and `...animal.fish.WaterAnimal` in 1.21.11, 26.1.2 and 26.3. The swap point (1.21.11) is exact. `travel(Vec3)` exists on `LivingEntity` in 1.21.1 and 26.3 and is the vanilla squid's own override (26.3 `Squid.java:210-212`). 26.3 still calls `travel` for server mobs (`LivingEntity.java:3235-3236`). `WaterAnimal.handleAirSupply` resets air to 300 in water and drowns at -20 (1.21.1 and 26.3), so `strandedAir` gives about 220 ticks (deviation 2). `Mth.RAD_TO_DEG` exists in both. `ShellSkater` uses `EntitySpawnReason` / `create(level, reason)` / `createAnimalAttributes`, which are rewritten for below 1.21.2 by `stonecutter.gradle:195,236,238`. The leftover unused `MobSpawnType` import on 1.21.1 is the documented ecj warning. `SpawnPlacementTypes.IN_WATER` and `ON_GROUND` exist on every line (1.20.5+), so no per-version spawn code is needed. No leniency-only compile was found.
- **Spawn placement.** Drifters and rays use `IN_WATER` + `MOTION_BLOCKING_NO_LEAVES` (`J/registry/ModSpawnPlacements.java:53-72`), which is vanilla's squid registration. The predicate needs water at the cell and above it, plus Y below 0 for the ray. `WaterAnimal` passes `checkSpawnRules` (walk value 0) and `checkSpawnObstruction`. Existing entries are unchanged: lines 34-46 are as before, and the new `water`/`deepWater` helpers are private and used only by the two Europa rows.
- **Biome spawners (both trees).** All ten Europa biomes match design 5.6 exactly in weights and counts (`R` `spawners`, and `R263` `minecraft:gameplay/natural_mob_spawns` with `modifier: overlay`, `spawns_by_category`, `count` int or `uniform`). Temperatures: natural 0.0, rooted 0.0, hydrated and living 0.2 in both trees, as spec 3.3 specifies (V4-01 is about the spec value). `has_precipitation` is false on all ten. `hazard/cold_mild` contains the trio (F09).

## Verdict

**0 BLOCKER, 2 MAJOR (V4-01, V4-02), 2 MINOR (V4-03, V4-04), 6 NOTE (V4-05..V4-10).**

Nothing found would fail at registry or data load on any cell, and the six other worlds' terraforming, breathing, weather and card lines are unchanged. The verifier fixes V01-V05, V07 and V3-02..V3-05 are done as specified. Two things need fixing before release:
- **V4-01:** the terraformed Europan sea and leads will freeze permanently through vanilla's height-adjusted temperature, so the trio temperature must rise to about 0.35, and spec 3.3 must be amended to match.
- **V4-02:** the Vent Ray's search cannot see the vent it circles, so it does not hold a circle or settle as designed.
