# Nerospace 2.4.0 — seams a new world touches (survey 2026-11-18)

Nothing was modified; no git or gradle was run. Paths are relative to the repo root; `J` = `common/src/main/java/za/co/neroland/nerospace`, `R` = `common/src/main/resources`, `R263` = `common/src/main/resources-26.3`, `T` = `common/src/test/java/za/co/neroland/nerospace`.

Three findings that shape the plan:
- **No "how to add a planet" doc exists** in `docs/`, `wiki/` or `AGENTS.md`. The seam list below is derived from code.
- **No loader Java is per-world.** All three loaders call shared sinks, so a new world needs zero edits in `fabric/`, `forge/`, `neoforge/` Java. The only loader-side per-world file is a generated NeoForge 26.3 dimension-type overlay.
- **Hazards do not change with terraform stage.** Terraforming changes breathability and gravity only (section 6).

**`PlanetHazards.java`**:
- `at(level, pos)` resolves in order: weather radiation, then biome tags `hazard/radiation`, `hazard/heat`, `hazard/cold`, then the trait hazard (lines 45-71).
- `frigidCold` = band FRIGID or a cold-tagged biome (105-112). Frigid needs the Cryo suit; plain COLD is kept out by any Tier 2 class suit.
- `radiationLevel` (152-169); `isNative` reads `#nerospace:native_fauna` (40-43).
- `HazardOrderRules.ORDER = [RADIATION, HEAT, COLD]`; `SuitClass {NONE, T1, T2, THERMAL, CRYO}`.

**`RadiationRules.java`**: `DAMAGE_THRESHOLD = 2`, `MAX = 3`, `DUST_STORM_LEVEL = 2`. Nyxara biome ids are hardcoded strings. `effective()` branches on `DUST_STORM` and `FLARE` only. `J/block/rules/RadShadeRules.java` plus `ModTags.Blocks.RADIATION_SHADE` (`registry/ModTags.java:112`, `R/data/nerospace/tags/block/radiation_shade.json`) are read only by `nyxara/NyxaraCrystalHazards.java:29`: a tagged block in the 3 cells above the head lowers ambient radiation by 1.

**`WeatherEvent.java`**, in order: `NONE, SPORE_BLOOM, DUST_STORM, ASH_FALL, DIAMOND_DUST, FLARE`. Persisted by name, so appending is safe.

**`WeatherParams`**: `(event, meanIntervalTicks, minDurationTicks, maxDurationTicks)`, plus `NONE` and `scaled()`.

**`WeatherMachine`**: CLEAR → RISING → PEAK → FADING, stepped every 20 ticks, ramp 0.02/s, target 0.4..1.0.

**`PlanetWeather.java`** has event-specific code: `raisesRadiation` (line 153, DUST_STORM/FLARE) and `solarFactor` (line 183, DUST_STORM). Per-planet effects register through `WeatherEffects.Registry`, `DriftWeather` and `CrystalStageBlock.register`.

**`ClockSource {PLANET_CLOCK, LEVEL_TIME}`**. `PlanetClock` is generic over `Planets` (phase, daylight, dayNumber, tick, set, freeze, sync).

## 6. Gravity, oxygen and hazards per dimension

- **Gravity** (`J/world/gravity/GravityManager.java:79-106`), in priority order: block overrides, biome tags `gravity_micro/low/high`, terraformed chunk flag → 1.0, then `PlanetTraits.defaultGravity`; all scaled by the config multiplier. Declared on the planet class; the tag is optional.
- **Oxygen** (`J/world/OxygenManager.java:116-118`): `isAirless` = `traits().airless()`. Breathable zones are oxygen fields, pads, a terraformed chunk (`:397`) or a terraform overlay at stage ≥ 1 (`:406-407`).
- **Cold / radiation**: the trait `hazard` + `temperatureBand` + `radiation` on `PlanetTraits`, plus optional biome tags `hazard/{cold,heat,radiation}` and weather. An unshielded hazard multiplies O₂ drain (`:184-186`); radiation at level ≥ 2 also damages.
- **Terraform stage does not change the hazard.** `HazardModelTest.matrix` gives `terraformed_mars_living` the same row as the dunes (`CC......`) and `terraformed_tundra` the same as Glacira (`CCCCCC..`). Hazard only bites while exposed, so breathable terraformed ground effectively removes it; gravity normalises to 1.0.
- For a cold ice world the Glacira pattern is `Hazard.COLD` + `TemperatureBand.FRIGID` (Cryo suit only). Mars is COLD band (any T2 suit), with `mars_polar` tagged `hazard/cold` making that biome frigid.
