### Decisions and deviations from the amendments

1. **Terraform table pulled forward from WP4.** `TerraformTablesTest.tablePerPlanet` requires a table for every planet but
   the station, so WP1 ships the real `EuropaTerraform.TABLE` (design 10.1 with `flora = List.of()`), `ORDER` index 7,
   `EuropaPlanet` `terraformTarget = terraformed_europa_living`, the three trio biome files (temperatures 0.0 / 0.2 / 0.2, in
   `hazard/cold_mild`, no spawners) and the four Monitor lang keys. Consequences until WP4: a Terraformer works on Europa
   through stages 1-2 with the existing code; stage 3 has no `OPEN_OCEAN` pass yet, so the sea does not open; no herd is seeded.
2. **`TerraformTablesTest.planetRules`**: "flora is never empty" became "flora is empty exactly for an `OPEN_OCEAN` table"
   (the amendments' F10 makes Europa's flora empty).
3. **`TerraformFaunaTableTest`**: the table names `nerospace:lantern_drifter`, an entity WP4 registers. The test gained a
   `PENDING` set holding that one id; it fails as soon as the id is registered, so WP4 must delete the entry.
4. **Surface rules**: each biome branch writes its block under a `stone_depth` floor condition at offset 0 and again at the
   amendments' offset (2, 4, 3). The output is identical to 2.5; the extra offset-0 condition is there because
   `TerraformTablesTest.surfaceBlocksAreTerraformable` only recognises offset 0 as "surface".
5. **Sky profile**: `stars.sizeScale` is 0.75, not the design's 1.0 (`SkyAssetsTest` pins 0.75 on every world as an owner
   ruling); a two-key constant `gradient` was added (the same test requires at least two keys; Luna has a constant one too);
   `nightShade.texture` is `…/terminator.png` (the spelling the other profiles use). Otherwise design 8.1 with the amendments.
6. **Jupiter still**: `gas_giant` already implements F13's closed loop (turbulence periodic in an eighth of a turn, drift
   sign +1 / -1 / 0 by band, the spot's band still), so WP6's frames `gas_giant("jupiter", 128, frame=i)` will match the
   still (`frame=0`). Not viewed in motion.
7. **`PlanetNoiseTest`**: Europa could not join the `ownNoise` roster (that case asserts ids under `nerospace:<planet>/overworld/`);
   a parallel case `ownNoiseAuthored` asserts the same properties for `nerospace:europa/<name>`.
8. **Two-event step**: the whole step lives in the pure `WeatherPickRules.step(machine, primary, secondary, enabled,
   mayStart, random)`; `PlanetWeather.stepLevel` calls it. Extra helper `rollsSecondary`. `WeatherPickRulesTest.marsUnchanged`
   runs 40,000 seeded steps through the old call and the new one and compares every field and the RNG position.
9. **`ColdShelterRules.cacheHit`** takes a `hasEntry` flag as its first argument. Dispatch follows the amendments' table
   (Nyxara -> `NyxaraWarmth`, Europa -> `EuropaWarmth`, else false); before 2.4 every planet asked `NyxaraWarmth`, which is
   false wherever no flare runs, and only Nyxara had flares, so the answers are the same. The 10-tick cache also applies to Nyxara.
10. **Loot**: besides the four tables of 3.4, `europium_ore` (silk / 1 `raw_europium`, no fortune), `cryovent` (silk / 2
    `europa_ice`), `hydrothermal_vent` (silk / 1 `vent_basalt`) and `tube_mat` (silk or shears, else nothing) are already in
    their final design form rather than self-drops. `brine` is `noLootTable()` and has no file (so 20 tables per tree, not 21).
11. **`requiresCorrectToolForDrops`** is set on every block of hardness 1.5 or more; the soft ones (`europa_ice`, `chaos_ice`,
    `lineae_salt`, `penitente_blade`, `tube_mat`, `europium_lamp`) drop by hand.
12. **Biome ambient sound** (`nerospace:ambient.europa.loop`) is left out of the seven natural biomes: the sound event is
    registered in WP4, which re-runs the biome overlay tool anyway.
13. **`brine_bucket` texture** comes from a new generator family (`item_bucket`) instead of hand-authored art.
14. `needs_diamond_tool.json` did not exist in the repo and was created.

### Deviations from the amendments

1. **Cryovent recharge is a scheduled tick, not a random-tick chance.** A random tick reaches a block about once per
   1,365 ticks at speed 3, so no chance gives a 600-tick mean. The tap schedules a tick 600 ticks ahead (exact, saved
   with the chunk). An uncharged vent with no tick pending takes random ticks and schedules the same delay.
   `VentTapRules` has `RECHARGE_TICKS`, no `rechargeChance()`.
2. **Brine does not implement `BucketPickup`.** Its signature differs across the 27 cells and no class in the repo
   overrides it. The block's `useItemOn` does the pick-up, which runs before the bucket's own use. A dispenser with an
   empty bucket does not pick brine up.
