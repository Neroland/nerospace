- **Reviewed:** `docs/decisions/2.4.0-europa.md` (114,710 bytes, 1,512 lines), with `2.4.0-seams.md`, `2.4.0-survey.md` and `AGENTS.md`, against the 2.3.1 tree.
- **Date:** 2026-11-20.
- **Reviewer:** an independent agent that did not write the design. Read-only review: no Java, resource, tool, Gradle or git was touched; nothing was compiled or run in game.
- **Shorthand:** `J` = `common/src/main/java/za/co/neroland/nerospace`, `R` = `common/src/main/resources`, `R263` = `common/src/main/resources-26.3`, `T` = `common/src/test/java/za/co/neroland/nerospace`. Section numbers refer to the design.

Severity: **MAJOR** = fix in the design before any build; **MINOR** = fix during the build; **NOTE** = be aware.
