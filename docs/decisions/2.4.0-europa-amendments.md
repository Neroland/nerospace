# Nerospace 2.4.0 — Europa amendments (final, overrides the design)

Written 2026-11-20 against the 2.3.1 tree. Read `2.4.0-europa.md` (the design) first, then this file.
**Where the two differ, this file wins.** It resolves every finding of `2.4.0-europa-review.md` (F01–F39).
Private dev notes; not part of the wiki.

Shorthand: `J` = `common/src/main/java/za/co/neroland/nerospace`, `R` = `common/src/main/resources`,
`R263` = `common/src/main/resources-26.3`, `T` = `common/src/test/java/za/co/neroland/nerospace`,
`E` = `J/world/planet/europa`, `TE` = `T/world/planet/europa`. "Both trees" = `R` and `R263`.

Owner decisions applied (not open): build all of Europa in this release; band `FRIGID` + mild tag under the ice;
terraformed Europa is not breathable (`NO_ATMOSPHERE`); every block has a survival path and a recipe use;
`secondaryWeather` and sky `Rotation` are both taken; brine is a block; no new per-player record; append-only.
No dev client is available to the builder, so nothing below depends on in-game tuning: every number is final
and each invariant has a headless test.

Evidence read for this file (beyond the review): `stonecutter.gradle:648-820` (`legacyWorldgen`),
`tools/gen_planet_noise.py`, Luna and Glacira `noise_settings` in both trees, Luna's 26.3 density functions,

## 2. Worldgen specification, final (resolves F01, F02, F30; replaces design 5.1–5.5 and 5.7)

Principle: nothing here needs tuning. Layer boundaries are linear Y ramps; the only randomness is 2D noise that is
**clamped to [-1, 1] before it is scaled**, so each boundary has an exact Y interval that a test can compute from
the JSON. No splines, no 3D noise, no aquifers, no carvers, no caves, no ore veins, no beardifier, no blending.

### 2.1 Numbers (also constants in `E/EuropaNumbers`)

| Constant | Value | Meaning |
|---|---|---|
| `MIN_Y` / `HEIGHT` | -64 / 384 | same box as Luna (`dimension_type/europa.json`: `min_y` -64, `height` 384, `logical_height` 384) |
| `SEA_LEVEL` | 88 | open cells with y < 88 are water (top water block Y 87) |
| `FLOOR_MIN..FLOOR_MAX` | -44..-20 | sea-floor boundary. Always solid at y <= -45; always open at y >= -20 |
| `ROOF_MIN..ROOF_MAX` | 84..100 | shell underside. Always open at y <= 84; always solid at y >= 101 |
| `SURFACE_MIN..SURFACE_MAX` | 176..212 | shell top. Always solid at y <= 175; always air at y >= 212 |
| `BIOME_SURFACE_Y` | 168 | surface biomes at y >= 168 (depth <= 0.1875) |
| `BIOME_OCEAN_Y` | 80 | ocean biomes at y < 80 (depth >= 0.875); shell biome Y 80..168 |
| `BIOME_VENT_Y` | -8 | vent-field biome at y <= -8 (depth >= 1.5625) |

Resulting layers: basalt floor -64..(-44..-20); ocean up to Y 87 (64 to 108 blocks of water under the roof);
air domes where the roof is above 88 (roof 89..100); solid shell (roof)..(surface), 76 to 128 thick; surface
176..212. Ocean water column is never shallower than 104 blocks (-20..84).

### 2.2 Density, written once, emitted in two dialects

`ramp(y0 -> v0, y1 -> v1)` is the clamped Y gradient. `N(id, s)` is
`clamp(noise(nerospace:europa/<id>, xz_scale s, y_scale 0), -1, 1)`.

```
topside   = ramp(160 -> +1, 224 -> -1)
          + 0.375 * N(surface, 1.0)
          + 0.4   * clamp(erosion - 0.35, 0, 0.625) * abs(N(rafts, 1.0))        // chaos rafts: 0 .. +0.25
          - 0.125 * clamp(1 - 20 * abs(ridges), 0, 1)                           // lineae trough: -0.125 .. 0
underside = ramp(72 -> -1, 112 -> +1)  + 0.4 * N(underside, 1.0)
seabed    = ramp(-56 -> +1, -8 -> -1)  + 0.5 * N(seabed, 1.0)
final_density = interpolated( max( seabed, min( underside, topside ) ) )
depth     = ramp(-64 -> 2.0, 320 -> -1.0)                                       // = (192 - y) / 128
```

`erosion` and `ridges` are the same density-function files the biome source reads, so chaos relief and the
lineae trough sit exactly under their biomes (thresholds 0.35 and 0.05 are shared with 2.4).

Why the bounds are exact: topside = (192 - y)/32 + o with o in [-0.5, +0.625], so the zero is at
y = 192 + 32 o in [176, 212]. underside = (y - 92)/20 + o, o in [-0.4, 0.4], zero at 92 - 20 o in [84, 100].
seabed = (-32 - y)/24 + o, o in [-0.5, 0.5], zero at -32 + 24 o in [-44, -20]. Every |o| < 1, so no ramp
saturates before its zero. All six ramp end points (-56, -8, 72, 112, 160, 224) are multiples of 8 above
`MIN_Y`, i.e. on interpolation cell corners (cells are 4 x 8 x 4), so trilinear interpolation of a function that
is linear in y between corners is exact in y and a convex mix of offsets in x/z: the intervals survive
interpolation unchanged. The three ramps are separated by more than 60 blocks, so in any cell where the sign
changes only one ramp is active.

### 3.1 Eclipse window and `planetSolar` (F06)
